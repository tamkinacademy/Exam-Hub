# ইলম পরীক্ষা কেন্দ্র (শুধু GitHub Pages-এ চলবে)

কোনো সার্ভার লাগে না। সাইটের ফাইল থাকবে GitHub Pages-এ, আর ডেটা (নিবন্ধন, উত্তর, ফলাফল) থাকবে ফ্রি Firebase-এ।
কোনো কার্ড লাগে না, শুধু একটা Google অ্যাকাউন্ট লাগবে।

> আগে দেখে নিতে চাইলে কিছু না করেই ফাইলগুলো GitHub-এ তুলে Pages চালু করুন। সাইট **ডেমো মোডে** চলবে
> (ডেটা শুধু ওই ব্রাউজারে থাকে, অ্যাডমিন পাসওয়ার্ড `demo1234`)। সত্যিকারের পরীক্ষার আগে নিচের ধাপ ২ করতেই হবে।

---

## ধাপ ১: GitHub-এ তোলা

1. github.com-এ নতুন রিপোজিটরি বানান (নাম যেমন `exam`)। **Public** রাখুন (ফ্রি Pages-এর জন্য)।
2. **uploading an existing file** চেপে এই ফোল্ডারের **ভেতরের সব ফাইল ও ফোল্ডার** টেনে দিন
   (সব ফাইল একই সারিতে, কোনো ফোল্ডার নেই)। Commit করুন।
3. রিপোজিটরির **Settings → Pages**-এ যান। Source: **Deploy from a branch**, Branch: **main**, Folder: **/(root)** → Save।
4. এক-দুই মিনিট পর `https://আপনার-নাম.github.io/exam/` লিংকে সাইট খুলবে।
   অ্যাডমিন: `https://আপনার-নাম.github.io/exam/admin.html`

## ধাপ ২: Firebase (ডেটাবেস) চালু করা, একবারই লাগবে

1. https://console.firebase.google.com খুলে Google দিয়ে ঢুকুন → **Add project** → নাম দিন → (Google Analytics বন্ধ রাখুন) → Create।
2. বাঁ পাশে **Build → Firestore Database → Create database** → Location: `asia-south1` (মুম্বাই, বাংলাদেশের কাছে) → **Production mode** → Create।
3. **Build → Authentication → Get started → Sign-in method → Email/Password** চালু করুন → Save।
4. Authentication-এর **Users** ট্যাবে **Add user** চাপুন। আপনার ইমেইল ও একটি শক্ত পাসওয়ার্ড দিন। **এটাই আপনার অ্যাডমিন লগইন।**
5. Firestore-এর **Rules** ট্যাবে যান। সব মুছে এই রিপোজিটরির `firestore.rules` ফাইলের পুরো লেখা পেস্ট করুন।
   ফাইলের ভেতরে `admin@example.com` লেখাটা খুঁজে **নিজের অ্যাডমিন ইমেইল** (ছোট হাতের অক্ষরে) বসান → **Publish**।
6. উপরে ⚙ (Project settings) → নিচে **Your apps** → `</>` (Web) আইকন → একটা নাম দিয়ে Register app।
   তখন `firebaseConfig = { apiKey: ..., ... }` দেখাবে। ওই মানগুলো কপি করুন।
7. GitHub-এ `config.js` ফাইল খুলে পেন্সিল (Edit) চেপে `adminEmail` ও `firebase`-এর মানগুলো বসিয়ে Commit করুন।
8. এক মিনিট পর সাইট রিফ্রেশ করুন। উপরের লাল ডেমো বার চলে গেলে বুঝবেন Firebase যুক্ত হয়েছে।
   `admin.html`-এ গিয়ে ধাপ ৪-এর পাসওয়ার্ড দিয়ে ঢুকুন।

> `apiKey` গোপন জিনিস নয়, পাবলিক রিপোজিটরিতে থাকলে সমস্যা নেই। সুরক্ষা আসে `firestore.rules` থেকে।

## পরীক্ষা নেওয়ার নিয়ম (আপনার কাজ)

1. অ্যাডমিনে **পরীক্ষা → নতুন পরীক্ষা** বানান। সময়সূচি ঠিক করুন, **প্রকাশ করুন** চালু রাখুন।
2. **প্রশ্ন** বাটনে গিয়ে প্রশ্ন দিন। Word থেকে একসাথে পেস্ট করতে **টেক্সট থেকে ইমপোর্ট** ব্যবহার করুন:
```
১. রাসূলুল্লাহ ﷺ কোথায় জন্মগ্রহণ করেন?
ক) মক্কা
খ) মদিনা
গ) তায়েফ
ঘ) জেদ্দা
উত্তর: ক
ব্যাখ্যা: মক্কায় জন্ম। (ঐচ্ছিক)
```
3. লিংক শেয়ার করুন। নিবন্ধনে প্রত্যেকে রোল ও পাসকোড পাবে।
4. ফি থাকলে **নিবন্ধন** পাতায় TrxID মিলিয়ে **অনুমোদন** দিন।
5. পরীক্ষা শেষ হলে **ফলাফল → ফলাফল প্রকাশ করুন** চাপুন। তখন নম্বর হিসাব হয়ে মেধাতালিকা, সার্টিফিকেট ও উত্তর পর্যালোচনা খুলে যায়।
   প্রশ্নের উত্তরে ভুল ধরা পড়লে ঠিক করে **নম্বর পুনরায় হিসাব** চাপুন।

## জেনে রাখুন (গুরুত্বপূর্ণ)

- **নম্বর আপনি প্রকাশ করার পরই দেখা যায়।** সার্ভার নেই বলে সঠিক উত্তর অংশগ্রহণকারীর ব্রাউজারে পাঠানো হয় না (নকল ঠেকাতে)। তাই জমা দেওয়ার সাথে সাথে নম্বর দেখানো যায় না।
- **ফ্রি সীমা (Firebase Spark):** দিনে ২০ হাজার লেখা ও ৫০ হাজার পড়া। একটি পরীক্ষায় একজন গড়ে ২০-৩০টি লেখা করে। তাই একদিনে মোটামুটি ৫০০-৭০০ জন নিরাপদে পরীক্ষা দিতে পারবে। এর বেশি হলে ফ্রি সীমা পেরোতে পারে। বড় আয়োজনে পরীক্ষার সময়সীমা কয়েক দিনে ছড়িয়ে দিন, অথবা Firebase-এর Blaze প্ল্যান নিন (ব্যবহার না বাড়লে বিল প্রায় শূন্য)।
- **সর্বোচ্চ অংশগ্রহণকারী সীমা** এই ভার্সনে নেই (সার্ভার ছাড়া নিখুঁতভাবে গোনা যায় না)।
- নিয়মিত **সেটিংস → ব্যাকআপ ডাউনলোড** করে ফাইলটি নিজের কাছে রাখুন।
- অ্যাডমিনের পাসওয়ার্ড বদলাতে Firebase → Authentication → Users থেকে Reset password করুন।
- ফি নিয়ে পুরস্কার দেওয়ার বিষয়ে চালুর আগে একজন আলেমের পরামর্শ নিন। ফি ০ রেখে স্পনসরের টাকায় পুরস্কার দিলে ঝুঁকি থাকে না।
- ডোমেইন লাগালে Pages সেটিংসের **Custom domain** ঘরে বসান।

## ফাইল কাঠামো
```
index.html        ইউজার সাইট
admin/            অ্যাডমিন প্যানেল
assets/config.js  আপনাকে এই একটা ফাইলই ঠিক করতে হবে
assets/           বাকি কোড ও ডিজাইন
firestore.rules   Firebase-এ পেস্ট করার নিরাপত্তা নিয়ম
```
